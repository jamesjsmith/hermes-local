# Privacy notice for Hermes Local

Hermes Local is a personal assistant app that runs on its owner's own computer. It is used only by its owner and is not offered to the public.

When the owner connects their Google account, the app reads and changes the owner's own Google Calendar, Drive, Docs and Sheets, and reads the owner's own Gmail and contacts. It does this only to carry out the owner's requests.

This data stays on the owner's computer. It is not sold, not shared with anyone else and not sent to any server run by the app. The access token is stored only on that computer, and access can be removed at any time at https://myaccount.google.com/permissions

Questions: open an issue in this repository.
